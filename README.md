# Estudos de Visão Computacional

Repositório com anotações, experimentos e exercícios práticos de visão computacional.

## Conteúdo

- `notebooks/`: notebooks de exemplos práticos com bibliotecas de Visão Computacional
- `opencv/`: exemplos práticos com OpenCV
- `pytorch/`: exemplos com Pytorch
- `tensorflow & keras/`: Exemplos práticos com TensorFlow e Keras.

## Objetivo

Este espaço serve para organizar aprendizados, testar ideias e reunir exemplos que ajudam no estudo de processamento de imagens e deep learning aplicado a visão computacional.

## Como usar

1. Instale as dependências do projeto:

```bash
pip install -r requirements.txt
```

2. Abra os notebooks ou execute os scripts Python dentro das pastas correspondentes.

## Observação

O repositório está em constante atualização conforme os estudos avançam.
